# Local roots.<br><em>Shared questions.</em>

<p class="page-lead">An informal network of people and organisations, connected by an interest in inclusive circus and movement.</p>

We have grown through personal relationships, Erasmus+ projects and continued exchange. The network currently has no separate legal entity. Each organisation brings its own identity, work and responsibilities.

## Our current circle

The following overview reflects the current working group described for this draft. People, affiliations and the wording of profiles need each organisation’s confirmation; this is not a formal membership register.

## A wider community

The current circle sits within a wider field of relationships. Existing collaborations and publications also include Circusatelier Woesh, Quat Props and Hula Hoop Integral. Project participation, contribution to a publication and membership of this emerging network are distinct relationships.

We would like to exchange with other European circus networks as this work develops.
