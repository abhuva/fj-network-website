# Share the process.<br><em>Credit the people.</em>

<p class="page-lead">We want people to find, understand and build on what we learn together.</p>

Openness is part of the direction proposed for this network. Clear documentation, accessible formats and explicit permissions make that useful in practice.

## What is already in this draft

- **Portable content.** Pages are stored as UTF-8 Markdown in a Git repository.
- **Static delivery.** Zensical builds the website as HTML and CSS, without visitor accounts or a database.
- **Structured information.** The [draft organisation directory](assets/data/network.json) uses JSON with stable identifiers, country codes, sources and review status. Its format is described in a [JSON Schema](assets/data/network.schema.json).
- **An accessible baseline.** Semantic headings, keyboard navigation, visible focus, responsive layouts and local assets are part of this implementation. A full accessibility audit is still to come.

## What we propose for shared resources

Every resource should identify its author, source, language, version and reuse terms. Adaptations and translations should remain connected to their originals. We should make clear whether something is a personal reflection, a teaching suggestion or a research finding.

We also want people to be able to suggest corrections without needing to understand Git. For now, [contact a participating organisation](connect.md); a shared contribution process still needs agreement.

## Reuse and licensing

The original website code and original SVG illustrations in this repository are available under the MIT licence. The licence file describes its scope.

**A shared licence for the network’s texts and directory has not yet been agreed.** Publicly readable does not automatically mean openly licensed. The directory therefore records its licence as `null`, and external publications retain their own rights and reuse conditions. Before releasing contributed material, we will need the contributor’s approval of its licence.
